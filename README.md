# PolyUrethanesCrosslinkinker
Автоматизированный пайплайн для МД-моделирования процесса сшивки полимеров (LAMMPS + MDAnalysis). Включает итеративный алгоритм образования связей (OH + NCO) с проверкой стерических препятствий, динамическое перестроение топологии (GAFF/RESP) и температурный отжиг для обхода стеклования.

# LAMMPS Polymer Cross-linking Pipeline

Автоматизированный молекулярно-динамический пайплайн на Python и LAMMPS для моделирования процесса химической сшивки полимеров (на примере образования полиуретановых сеток из реакционных групп OH и NCO). 

Скрипт итеративно сшивает систему, динамически обновляя топологию (типы атомов, заряды, связи, углы, диэдралы и импроперы), и запускает промежуточные этапы релаксации (simulated annealing), постепенно увеличивая радиус захвата реакционных групп.

## 🌟 Основные возможности

* **Динамический радиус сшивки:** Постепенное увеличение `cutoff` от 3.5 Å до 6.0 Å в случае падения скорости реакции.
* **Фильтрация реакций:** Проверка на стерические затруднения (steric clashes) перед образованием новой связи. Учитывается геометрия молекул.
* **Автоматическое перестроение топологии:** Использование `MDAnalysis` для генерации новых топологических параметров на лету с опорой на `ttree_assignments.txt` (GAFF).
* **Пересчет зарядов:** Корректировка парциальных зарядов (RESP) для сшитого состояния с сохранением нейтральности.
* **Умная релаксация (LAMMPS):** 
  * Мягкая релаксация (`nve/limit`) для предотвращения "взрыва" системы при появлении новых связей.
  * Стандартный отжиг (`relax.in`) для диффузии цепей.
  * Усиленный высокотемпературный отжиг (`extra.in`) — активируется автоматически при падении конверсии (витрификации/стекловании) на максимальном радиусе.

## 🛠 Требования (Dependencies)

* **LAMMPS** (Скомпилированный с пакетом `GPU`, так как используются флаги `-pk gpu 1 -sf gpu`).
* **Python 3.x**
* **Python библиотеки:**
  * `MDAnalysis`
  * `numpy`

## 📂 Структура файлов

* `master_loop.py` — Главный оркестратор пайплайна. Управляет циклами сшивки, радиусом отсечения и запускает LAMMPS.
* `crosslink.py` — Ядро алгоритма. Анализирует `.data` файл, находит пары, проверяет геометрию, обновляет графы связей и перезаписывает топологию.
* `relax.in` — LAMMPS-скрипт базовой релаксации (нагрев до 400 K, диффузия, охлаждение до 300 K).
* `extra.in` — LAMMPS-скрипт "спасательной" релаксации при застревании конверсии (нагрев до 500 K, длительная диффузия).
* `system.in.init` / `system.in.settings` — Базовые настройки силового поля системы (предоставляются пользователем). 
* `ttree_assignments.txt` — Файл параметров топологии (GAFF, предоставляются пользователем).
* `equilibrated.data` — Стартовый файл системы (подготоваливается пользователем).

1. Убедитесь, что у вас подготовлены стартовый файл `equilibrated.data`, файлы силового поля (`system.in.*`) и `ttree_assignments.txt`.
2. Откройте `master_loop.py` и отредактируйте параметры под вашу систему:
